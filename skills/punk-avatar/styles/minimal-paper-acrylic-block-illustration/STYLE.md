# 极简纸感丙烯色块插画

把照片或主题高度提炼成“粗糙白纸 + 轻手绘线 + 明显丙烯色块 + 大量留白”的小幅插画。不是写实复刻、照片线稿化、彩铅、蜡笔或水彩。

## 提炼

- 只保留一个主体或象征场景及其最有辨识度的轮廓、动作、空间关系和关键颜色。
- 人物保留姿态、发型和服装轮廓；宠物保留体态与标记；物体/建筑保留主要外形、功能结构和关键门窗。删除无关背景与装饰。
- 主题输入先转成一个可记忆的视觉瞬间，用一个小主体、动作或结构表达，不堆图标和解释文字。

## 材料

- 白纸纹理清晰、略粗糙，主体像手工丙烯平涂：色块完整、醒目、有轻微厚度、颗粒和不规则边缘。
- 使用 2–4 种鲜明主色，可加少量黑/深灰结构线；不要复杂渐变、发光、透明水彩或光滑数字填色。
- 线条细、轻、略断续和不稳定，仅提示轮廓、动作与结构；不用密集排线、工程制图或完整写实勾勒。

## 构图

- 主体通常占画面约 10%–20%，四周保留大面积有意留白；仅在必要时用几条线或一小块色面暗示环境。
- 保持一个视觉中心，安静、克制、童趣、轻松且诗意。即使作为头像，主体也应小而清楚，关键特征在缩略图中可读并远离边缘。

## 必须避免

满版主体、复杂透视、多中心、拥挤背景、超过四种主色、写实细节、油画、商业卡通、3D、AI 式精致堆砌、模板化构图、相框、Logo、水印或大量文字。
